# Сегментация изображений с использованием PyTorch

Данный проект реализует задачу иерархической семантической сегментации с использованием библиотеки PyTorch. Проект основан на датасете Pascal-part и включает этапы загрузки данных, аугментации, обучения и визуализации результатов. В качестве основной метрики используется mean Intersection over Union (mIoU), рассчитанный для разных уровней вложенности классов.

---

## Тестовое задание

### Цель
Реализовать и обучить модель, позволяющую выполнять иерархическую семантическую сегментацию на датасете Pascal-part.

---

## Данные

Обучение модели производится на датасете Pascal-part. Подготовленные данные и разметку можно загрузить по следующей [ссылке](https://drive.google.com/file/d/1unIkraozhmsFtkfneZVhw8JMOQ8jv78J/view?usp=sharing).

### Описание структуры данных

- В папке `JPEGImages` находятся исходные изображения в формате jpeg.
- В папке `gt_masks` находятся маски сегментации в формате numpy.

Маски можно загрузить с помощью функции `numpy.load()`.

### Иерархия классов

В датасете присутствуют 7 классов с следующей иерархической структурой (в скобках указан индекс класса):

```
├── (0) background
└── body
    ├── upper_body
    |   ├── (1) low_hand
    |   ├── (6) up_hand
    |   ├── (2) torso
    |   └── (4) head
    └── lower_body
        ├── (3) low_leg
        └── (5) up_leg
```

---

## Метрики

В качестве основной метрики используется mean Intersection over Union (mIoU). Для каждого уровня вложенности метрика вычисляется отдельно. При этом класс background (0) не учитывается при расчёте.

### Метрики для разных уровней вложенности

1. **mIoU<sup>0</sup>**: `body`
2. **mIoU<sup>1</sup>**: `upper_body`, `lower_body`
3. **mIoU<sup>2</sup>**: `low_hand`, `up_hand`, `torso`, `head`, `low_leg`, `up_leg`

### Результаты на валидации

- **Validation mIoU<sup>0</sup>:** 0.7771
- **Validation mIoU<sup>1</sup>:** 0.4560
- **Validation mIoU<sup>2</sup>:** 0.4918

Эти результаты демонстрируют, что модель хорошо справляется с определением тела в целом (mIoU<sup>0</sup>), но сложные структуры, такие как части тела (mIoU<sup>1</sup> и mIoU<sup>2</sup>), имеют более низкие показатели. Это объясняется сложностью разметки и меньшим количеством данных для обучения на мелких частях тела.

## Описание модели

Для выполнения задачи сегментации использовалась модель **DeepLabV3** с бэкбоуном **ResNet50**. Все веса бэкбоуна были разморожены, и обучение производилось для всей архитектуры, а не только для классификатора. Это позволило достичь более точных результатов за счёт оптимизации всех параметров модели.

Обучение производилось на видеокарте **GTX 1650 Ti**, что обеспечило ускорение вычислений и эффективное использование ресурсов.

---

## Результаты

Модель продемонстрировала хорошие результаты на многих изображениях, особенно при нормальном освещении и крупных объектах. Однако были отмечены следующие проблемы:

1. Ошибки на изображениях с экстремальными условиями освещения (очень яркие или тёмные).
2. Ошибки при обработке изображений, где объекты (люди) имеют маленький размер.

### Рекомендации по улучшению модели:

- Увеличить размер батча (**batch size**) для более стабильного обучения.
- Добавить **lr scheduler** для более эффективного управления скоростью обучения.
- Рассмотреть использование более мощных моделей, таких как **Swin Transformer** или **HRNet**, для задачи семантической сегментации, но для этого нужны ресуры. Их можно оптимизировать под мое железо, но придется идти на ухищрения в виде уменьшения батч сайза и тд.
