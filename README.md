# Сегментация изображений с использованием PyTorch

Данный проект реализует задачу иерархической семантической сегментации с использованием библиотеки PyTorch. Проект основан на датасете Pascal-part и включает этапы загрузки данных, аугментации, обучения и визуализации результатов. В качестве основной метрики используется mean Intersection over Union (mIoU), рассчитанный для разных уровней вложенности классов.

---

## Тестовое задание

### Цель
Реализовать и обучить модель, позволяющую выполнять иерархическую семантическую сегментацию на датасете Pascal-part.

---

## Данные

Обучение модели производится на датасете Pascal-part. Подготовленные данные и разметку можно загрузить по следующей [ссылке](https://drive.google.com/file/d/1unIkraozhmsFtkfneZVhw8JMOQ8jv78J/view?usp=sharing).

### Описание структуры данных

- В папке `JPEGImages` находятся исходные изображения в формате jpeg.
- В папке `gt_masks` находятся маски сегментации в формате numpy.

Маски можно загрузить с помощью функции `numpy.load()`.

### Иерархия классов

В датасете присутствуют 7 классов с следующей иерархической структурой (в скобках указан индекс класса):

```
├── (0) background
└── body
    ├── upper_body
    |   ├── (1) low_hand
    |   ├── (6) up_hand
    |   ├── (2) torso
    |   └── (4) head
    └── lower_body
        ├── (3) low_leg
        └── (5) up_leg
```

---

## Метрики

В качестве основной метрики используется mean Intersection over Union (mIoU). Для каждого уровня вложенности метрика вычисляется отдельно. При этом класс background (0) не учитывается при расчёте.

### Метрики для разных уровней вложенности

1. **mIoU<sup>0</sup>**: `body`
2. **mIoU<sup>1</sup>**: `upper_body`, `lower_body`
3. **mIoU<sup>2</sup>**: `low_hand`, `up_hand`, `torso`, `head`, `low_leg`, `up_leg`
